# Protein Secondary Structure Prediction

A deep learning project that predicts the 3D structure of protein sequences using PyTorch. Given a sequence of amino acids, the model labels each residue as part of an alpha helix (H), beta sheet (E), or coil/loop (C).

```
Input:   M  E  E  P  Q  S  D  P  S  V  E  P  P  L  S  Q
Output:  C  C  C  C  C  C  C  C  C  C  H  H  H  H  H  H
```

This is a sequence labeling problem — similar to named entity recognition in NLP, but for biology.

---

## What's inside

The notebook walks through the full pipeline: synthetic data generation using a Hidden Markov Model with real Chou-Fasman amino acid propensities, four different architectures (CNN, GRU, BiLSTM, and a CNN+BiLSTM hybrid), hyperparameter experiments (learning rate, dropout, activation functions), evaluation with confusion matrices and per-class F1, and a 3D visualization of the real human TP53 protein colored by our model's predictions.

The best model (BiLSTM) reaches **78.23% per-residue accuracy** on the test set.

## The biology (briefly)

Proteins are chains of amino acids — there are 20 of them, each represented by a letter. The sequence folds into a 3D shape, and the local geometry at each position is classified as one of three types:

- **Helix** — a coiled spring shape, common in membrane proteins and DNA-binding domains
- **Sheet** — flat strands that run parallel or antiparallel, often forming the core of proteins
- **Coil** — everything else; flexible loops that connect helices and sheets

Predicting this from sequence alone is useful because structure determines function, and structure is much harder to measure experimentally than sequence. AlphaFold won the Nobel Prize in Chemistry 2024 for solving the harder version of this problem (full 3D coordinates, not just H/E/C labels).

## Models and results

Four architectures were trained and compared:

| Model | Test accuracy | Parameters |
|-------|--------------|------------|
| CNN1D | 77.75% | 145K |
| BiGRU | 78.16% | 220K |
| **BiLSTM** | **78.23%** | **310K** |
| CNN + BiLSTM | 77.85% | 485K |

BiLSTM won. The key reason is bidirectionality — reading the sequence in both directions gives each position context from the entire sequence, not just what came before it. The hybrid model has more parameters but doesn't improve accuracy, which shows that adding complexity doesn't always help.

Per-class F1 on the test set (BiLSTM):

- Helix: 0.829
- Sheet: 0.820
- Coil: 0.648

Coil is the hardest class — it's defined by the absence of regular structure, so there's no strong sequence signal to learn from.

## The TP53 visualization

The last section of the notebook runs the trained BiLSTM on the full human TP53 tumor suppressor protein (UniProt P04637, 393 residues). The structure file comes from the AlphaFold Database. The results are rendered as an interactive 3D viewer in `tp53_3d.html` — open it in Chrome.

View 1 shows the AlphaFold confidence scores (pLDDT). View 2 shows our BiLSTM predictions: 37% helix, 15% sheet, 48% coil.

## Dataset

The training data is synthetic — 5,000 protein sequences generated by an HMM whose emission probabilities follow the Chou-Fasman propensity tables (real biochemical data). This avoids downloading large datasets while preserving biologically realistic amino acid composition per structure class.

For real experiments, the CB513 or CullPDB datasets are the standard benchmarks. State-of-the-art models on those datasets reach Q3 accuracies above 85%, typically using pre-trained protein language model embeddings (ESM-2, ProtBERT) instead of learned embeddings from scratch.
